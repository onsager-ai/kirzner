# Worked example and evidence labels

Start a fresh local instance, then run `python3 scripts/worked_example.py`. Use `--url http://127.0.0.1:PORT` for another loopback instance and `--result PATH` to choose the concise evidence JSON output; by default it writes `test-results/worked-example.json`.

The example starts with only product, objective, and constraints. Customer, verified capabilities, time, budget, channels, and prior materials remain unknown. Its product and technical source are grounded in Semon's README at `defe9d791a197902c5bebcba2e2b7fe87dd9a075`, whose verified README blob is `e3b46edb940efd51ca4e9f3ca6da958daee68892`.

The opportunity and experiment draft are labeled planning data assembled for this example. They are imported through a task-scoped return to exercise the real return path, but they are not output from an external agent or evidence that customer research occurred. Importing the opportunity creates no experiment approval. The script explicitly selects the draft to create an experiment and records a separate preparation-only approval.

The uploaded Semon excerpt is real pinned public documentation. Its task-scoped return wrapper is synthetic and records no external execution. The founder reviews the excerpt as technical preparation material only. Semon capture, private-log inspection, interviews, prospect contact, publication, and purchases do not occur.

The proposal separates technical capability evidence from business unknowns. Documentation supports the described capture and ordinary-read interfaces; it does not establish local availability, recurring coordination pain, participant access, urgency, demand, or willingness to pay. Counterevidence and those unknowns remain visible.

The real-product example stops after source-material review with zero actions, observations, and adopted learning. A separate browser journey uses labeled synthetic returns, material, actions, observations, and decisions to verify the full software loop. Those fixtures demonstrate application behavior, not external agent execution or business success.
