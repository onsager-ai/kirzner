# Worked example and evidence labels

Start a fresh local instance, then run `python3 scripts/worked_example.py`.
Use `--url http://127.0.0.1:PORT` for an alternate loopback instance.

The real product is Kirzner, with a brief grounded in its original README at
`6ee900ac7042e25866622d1958c520b3ba8a5784`. The external material is an excerpt
of Semon's implemented capture/read documentation at
`defe9d791a197902c5bebcba2e2b7fe87dd9a075`, verified through the GitHub
connector and the retained source archive. Both URLs are stored as evidence.

The opportunity is explicitly a hypothesis about interviewing founders who use
manual agent handoffs. Documentation supports the product/integration context;
it does not substantiate customer pain, demand, urgency, or willingness to pay.
Counterevidence and unknowns remain visible. The preparation proposal approves
zero-cost source review only. The imported external excerpt retains provenance
and is accepted only as technical material.

No acquisition action is recorded because none was performed. No business
observation or learning is manufactured. The founder can subsequently run a
real experiment outside Kirzner, record its action reference, compare the real
result to the original criteria, decide continue/adjust/stop, and explicitly
adopt a finding. An incomplete or negative result is valid.

The browser suite exercises that entire software path using clearly labeled
synthetic actions, observations, and materials. It also revises a proposal,
checks the need for fresh approval, imports duplicates/conflicts, and reloads
the workspace. Those fixtures demonstrate software behavior, not real business
success or real agent-session capture.
